# 작은 인사 — Python 방명록

`codex.md`의 요구사항에 따라 Day 01–08 수업의 FastAPI/Pydantic 구성을 유지한 작은 방명록입니다. **Python + FastAPI + Pydantic + SQLite + HTML/CSS**를 사용합니다. 맞춤 입력 알림, 우주 메시지·모션 제어, 새로고침 없는 좋아요에 작은 JavaScript 파일을 사용합니다. React, Vue, ORM, 외부 DB, 외부 폰트와 실행 중 유료 API는 사용하지 않습니다. SQLite는 Python에 내장되어 있습니다. 새 외부 패키지는 추가하지 않았습니다.

## 실행

저장소 루트 `C:\AIO_04_kjun`의 PowerShell에서:

```powershell
.\.venv\Scripts\python.exe day1-day8/main.py
```

브라우저에서 <http://127.0.0.1:8000>을 엽니다. 종료는 터미널에서 `Ctrl+C`입니다. HTML을 파일로 직접 열면 글 저장이 동작하지 않으므로 Python 서버로 접속해야 합니다.

별도의 환경이 필요한 경우, Python 3.10 이상을 설치한 뒤 프로젝트 폴더에서 실행합니다. 아래 `pip install`은 기존 수업에서 사용한 패키지를 해당 환경에 준비하는 명령입니다.

```powershell
cd C:\AIO_04_kjun\day1-day8
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## 기능과 화면

- 이름(1–24자)과 이야기(1–500자) 등록, 양끝 공백 제거와 서버 검증
- 본인 글 수정·삭제: 같은 브라우저의 작성자 쿠키 확인, 삭제 전 재확인
- 좋아요 체크·해제와 전체 개수 표시. 같은 브라우저에서 같은 상태를 반복 전송해도 중복 집계되지 않음
- 글마다 답글 펼치기·작성·수정·삭제. 답글의 수정·삭제도 해당 답글의 작성 브라우저에서만 가능
- 최신순 목록, 이름·본문 검색, 한 페이지에 6개씩 이동
- SQLite 파일 저장: 서버를 종료해도 영속 디스크의 파일은 유지
- 등록 후 GET 이동으로 새로고침에 따른 POST 재전송 방지
- 검증 실패 시 입력값 유지, 빈 목록·검색 결과 없음·등록 완료 안내
- 빈 값·공백만 입력 후 제출 시 첫 번째 입력란에 라벤더색 말풍선 표시, 입력을 채우면 해제. 스크립트를 사용할 수 없으면 브라우저 기본 필수 입력 검증과 서버 검증 유지
- 작은 화면에서는 작성 폼과 목록이 세로로 배치되는 반응형 화면
- 키보드 포커스, 입력 레이블, 본문 건너뛰기, 오류 알림과 동작 줄이기 설정 지원

첨부 레퍼런스의 큰 반투명 패널, 여백, 세리프 제목을 우주 테마로 재해석했습니다. 보랏빛 우주 배경, 아이보리 타이포그래피, 유리 카드와 행성 모션을 사용합니다. 영문 제목은 Georgia 계열, 한글 본문은 시스템 글꼴을 사용하며 원본 폰트와 완전히 동일한 글꼴은 아닙니다. 외부 폰트 다운로드가 없습니다. 예시 글을 실제 데이터처럼 자동 삽입하지 않습니다.

행성이나 ‘다른 별의 이야기’를 누르면 준비된 우주 문구 중 하나를 보여줍니다. 떠다니는 행성·별빛·별똥별은 CSS로 움직이며, ‘움직임 멈추기’ 버튼으로 정지할 수 있습니다. OS의 동작 줄이기 설정도 따릅니다. Pinterest의 Photography Landing Page UI Animation 영상에서 보이는 원형 이미지 전환을 참고해, 행성의 첫 등장에 원형 마스크 확장과 제목의 부드러운 등장을 적용했습니다.

## 데이터 구조와 규모

최초 접속 때 `data/guestbook.db`를 만듭니다. `entries` 테이블 하나만 사용하며 외래 키와 관계는 없습니다. DB 경로는 실행 위치에 영향을 받지 않습니다.

| 열 | SQLite 타입 | 용도 |
| --- | --- | --- |
| `id` | INTEGER PRIMARY KEY | 글 번호 |
| `name` | TEXT NOT NULL | 공개 이름 |
| `message` | TEXT NOT NULL | 공개 이야기 |
| `created_at` | TEXT NOT NULL | UTC+09:00 오프셋을 포함한 등록 시각 |
| `owner_hash` | TEXT NOT NULL | 작성자 쿠키의 SHA-256 해시. 화면에 노출하지 않음 |
| `likes_json` | TEXT NOT NULL | 좋아요를 체크한 브라우저 토큰 해시 목록. 기본값 `[]` |
| `replies_json` | TEXT NOT NULL | 답글의 ID·이름·본문·시각·작성자 해시를 담은 목록. 기본값 `[]` |

전체 저장 한도는 1,000개, 요청 본문은 8 KiB입니다. 1,000개에 도달하면 기존 글을 삭제하지 않고 새 등록을 거절합니다. 작은 SQLite 파일을 전제로 한 학습용 상한이며, 서비스 제공자의 무료 요금제 보장은 아닙니다. 동시 작성은 SQLite 트랜잭션으로 처리하며, 파일 잠금 대기는 최대 10초입니다. 단일 서버·단일 워커 사용을 권장합니다.

DB 위치를 지정하려면 실행 전 환경변수를 설정합니다. 상대 경로는 프로젝트 폴더 기준입니다.

```powershell
$env:GUESTBOOK_DB = "data/guestbook.db"
.\.venv\Scripts\python.exe main.py
```

로그인, 첨부파일, CAPTCHA, 자동 백업은 포함하지 않았습니다. 자동 도배 방지나 관리 기능이 없는 소규모 학습용 앱입니다. 화면의 출처 검사로 모든 자동 요청이 차단되지는 않습니다. 공개 입력란에는 연락처 등 개인정보를 적지 마세요.

## 수정·삭제 권한

처음 글을 등록하면 무작위 작성자 토큰을 HttpOnly·SameSite=Lax 쿠키에 저장합니다. HTTPS에서는 Secure도 적용합니다. 서버는 토큰 원문 대신 해시만 테이블에 저장합니다. 작성한 브라우저의 글에만 수정·삭제가 표시되며, URL을 직접 호출해도 서버에서 소유자를 다시 확인합니다. 수정은 원래 등록 시각과 글 번호를 유지합니다. 삭제는 카드의 ‘삭제’를 펼친 뒤 ‘삭제 확인’을 눌러 실행합니다.

쿠키 유효기간은 글·답글 등록 또는 좋아요 변경 시점부터 1년입니다. 다른 기기·브라우저, 쿠키 삭제 또는 만료 후에는 권한을 복구할 수 없습니다. 공유 브라우저의 사용자는 같은 작성자로 취급합니다. 기존 버전의 글은 작성자를 확인할 정보가 없으므로 그대로 표시하되 수정·삭제하지 못하게 보호합니다. 기존 DB에는 필요한 열만 자동 추가하며 글을 삭제하지 않습니다. 최초 업데이트 전 서버를 종료하고 DB를 백업해 두면 좋습니다.

## 좋아요와 답글 사용 방법

각 카드의 하트 ‘좋아요’를 누르면 체크되며 한 번 더 누르면 해제됩니다. 좋아요를 눌러도 페이지가 이동하지 않아 작성 중인 글은 유지됩니다. JavaScript가 실행되지 않아도 HTML 폼으로 체크·해제할 수 있으며 이때는 페이지가 새로고침됩니다. 좋아요 상태와 개수는 SQLite에 저장됩니다.

‘답글 N’을 펼쳐 이름과 이야기를 입력하면 해당 글에 답글을 남길 수 있습니다. 한 단계의 답글만 지원하며 답글 아래에 다시 답글을 다는 다단계 구조는 사용하지 않습니다. 본인 답글의 ‘수정’을 펼쳐 저장하거나 ‘삭제 → 답글 삭제 확인’을 누를 수 있습니다. 원글 작성자도 다른 사람이 작성한 답글을 개별 수정·삭제할 수 없습니다. 다만 **원글을 삭제하면 포함된 좋아요와 모든 답글도 함께 삭제**되므로 확인창에서 이를 안내합니다.

글 하나당 좋아요는 최대 1,000개, 답글은 최대 30개이며 답글의 이름·본문 제한은 원글과 같습니다. 별도 테이블·외래 키 없이 JSON 열에 보관하며, 조회·변경을 한 SQLite 트랜잭션으로 처리합니다. 원글 목록의 검색·페이지 수·전체 글 수에는 답글을 포함하지 않습니다. 쿠키 기반이므로 쿠키를 지우거나 다른 브라우저를 사용하면 다른 방문자로 취급되며, 사람 한 명당 하나를 보장하는 계정 기반 기능은 아닙니다.

Render 무료 플랜의 DB 초기화 특성은 좋아요와 답글에도 적용됩니다. **이 변경으로 SQLite 영구 보존이 가능해지는 것은 아닙니다.** GitHub 업로드 시 `main.py`, `templates/index.html`, `static/` 안의 이미지·CSS·JavaScript 파일도 함께 올려야 합니다.

백업은 서버를 종료한 상태에서 `data/guestbook.db`를 안전한 위치로 복사합니다. 복구도 서버를 종료한 상태에서 수행합니다. `.gitignore`로 DB와 가상환경을 소스 버전 관리에서 제외했습니다.

## 테스트

저장소 루트에서 기존 수업 환경으로 실행합니다. 시스템 임시 폴더 접근 제약을 피하기 위해 테스트용 DB를 프로젝트 안에 만듭니다.

```powershell
New-Item -ItemType Directory -Force day1-day8/.pytest_cache | Out-Null
.\.venv\Scripts\python.exe -m pytest day1-day8/test_guestbook.py -q --basetemp=day1-day8/.pytest_cache/tmp
```

`--basetemp`는 pytest가 매번 비우는 **테스트 전용 경로**입니다. 실제 데이터 디렉터리로 바꾸지 마세요. 새로운 환경에서 테스트하려면 `requirements-dev.txt`를 설치합니다. 테스트는 실행할 때마다 임시 SQLite를 사용하며 실제 방명록 DB를 바꾸지 않습니다.

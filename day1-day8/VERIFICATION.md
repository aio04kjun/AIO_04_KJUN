## HTTP와 화면 검증 범위

실제 Uvicorn 서버를 루프백 주소로 실행해 HTML과 CSS 응답을 확인했습니다. 테스트 서버는 검증 후 종료합니다. 검증 중 글을 등록하지 않아 실제 방명록은 빈 상태로 시작합니다.

브라우저 제어 도구에서 사용 가능한 브라우저 목록이 비어 있어 **실제 브라우저 스크린샷, 모바일 렌더링, 키보드 조작의 시각 QA는 수행하지 못했습니다.** CSS에는 800px·640px 반응형 규칙과 키보드 포커스 스타일을 작성했지만, 시각 검증 완료로 간주하지 않습니다.

로컬 실행 후 확인할 항목:

1. PC에서 왼쪽 작성 폼과 오른쪽 목록이 읽기 편하게 보이는지 확인합니다.
2. 휴대전화 폭에서 폼과 목록이 세로 배치되고 가로 스크롤이 없는지 확인합니다.
3. Tab 키로 이름 → 이야기 → 등록 버튼을 이동하고 포커스가 보이는지 확인합니다.
4. 글을 등록하고 새로고침해 중복 등록이 없는지, 서버 재시작 후에도 글이 남는지 확인합니다.

실제 호스팅 배포, 외부 접속, 부하 테스트 및 호스팅별 프록시 설정 검증은 수행하지 않았습니다. 무료 배포 제약과 공식 출처는 `DEPLOYMENT.md`를 참고하세요.

## 입력 알림 디자인 변경

브라우저 기본 유효성 버블 대신 세이지 그린의 맞춤 말풍선을 입력란 아래에 추가했습니다. 필수 값·공백 검사, 첫 오류 입력란으로 포커스 이동, 입력 수정 시 안내 해제는 `static/validation.js`에서 처리합니다. 스크립트가 실행되지 않으면 기존 브라우저 기본 검증으로 동작합니다. 서버 검증은 유지했습니다.

변경 후 기존 자동 테스트 16개가 다시 통과했고 JavaScript 파일 제공 경로의 200 응답과 CSP 설정을 확인했습니다. CSP는 같은 출처의 스크립트만 허용합니다. Node 실행 도구가 종료되어 별도 JavaScript 문법 검사는 완료하지 못했습니다. 실제 브라우저의 말풍선 표시·스크린리더 알림은 아직 시각·보조기기 검증을 수행하지 못했습니다.

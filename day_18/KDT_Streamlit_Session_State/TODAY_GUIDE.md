# 수업 전 안내: 메시지가 남는 화면부터 만들기

## 오늘 만들 결과물

메시지를 두 번 입력한 뒤 화면을 다시 실행해도 두 문장이 남는 작은 대화 화면을 만듭니다. 먼저 화면이 값을 기억하는 원리를 확인하고, 다음 학습에서 로그인과 사용자별 이력으로 넓혀 갑니다.

이번 실행 결과물은 1차시의 메시지 기록 화면입니다. 로그인·사용자별 DB 조회·AI 답변은 이후 진행 순서에 해당합니다.

설명용 예상 화면: 제목 아래 `저장된 메시지 수: 2`가 표시되고, `안녕하세요`와 `내 이름은 민수`가 입력 순서대로 말풍선에 나타납니다. `대화 비우기`를 누르면 수가 0이 되고 말풍선이 사라집니다.

## 오늘의 진행 순서

| 단계 | 직접 할 일 | 쌓이는 결과 |
| --- | --- | --- |
| 1 | 일반 목록으로 두 문장 입력 | 재실행 때 기록이 사라지는 문제 발견 |
| 2 | 목록을 session_state로 옮기기 | 두 문장이 함께 남는 화면 |
| 3 | 화면 다시 실행 버튼 누르기 | 새 입력 없이도 기록 유지 |
| 4 | 대화 비우기와 공백 검사 추가 | 기록을 직접 초기화하는 화면 |

`session_state`는 같은 화면 세션에서 재실행 사이에 값을 보관하는 공간입니다. 브라우저 새로고침은 여기서 누르는 `화면 다시 실행` 버튼과 동작이 다릅니다.

## 시작 전 확인

- ZIP을 먼저 압축 해제합니다. [lesson01/README.md](lesson01/README.md)를 엽니다.
- 실습 폴더는 예를 들어 `C:\AI4\Streamlit_Session_State\lesson01`입니다.
- Python, 코드 편집기, Windows CMD, 브라우저를 준비합니다. 패키지 설치는 수업 전에 끝냅니다. 정확한 명령과 각 역할은 교안 3번에 있습니다.
- 파이썬의 목록·딕셔너리·if·for를 사용합니다. 필요한 뜻은 교안에서 작은 예제로 다시 확인합니다.
- API 키·DB 계정·모델 다운로드는 필요하지 않습니다.

## 완료 확인

1. `안녕하세요`, `내 이름은 민수`를 차례로 제출하면 두 문장이 모두 보입니다.
2. `화면 다시 실행`을 두 번 눌러도 메시지 수는 2입니다.
3. `대화 비우기`를 누르면 0이 되고, `다시 시작`을 입력하면 그 한 문장만 보입니다.
4. 별도 새 탭으로 같은 앱을 열면 빈 기록으로 시작합니다.
5. “재실행 사이의 유지”와 “새로고침 뒤 복원”이 다른 기능임을 설명할 수 있습니다.

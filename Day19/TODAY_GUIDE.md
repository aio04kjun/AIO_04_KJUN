# 앞선 말을 참고하는 학습 도우미 만들기

## 오늘 만들 결과물

같은 계정의 대화를 다시 열어 “방금 알려준 방법으로 예제를 만들어줘”라고 이어 묻는 앱을 만듭니다. 마지막에는 대화별 학습 목표까지 AI에게 함께 전달합니다.

화면에 기록이 보이는 것과 AI에게 기록을 보내는 것은 별개입니다. 매 차시에서 말풍선과 **직전 요청에서 AI에게 보낸 메시지**를 함께 봅니다.

## 오늘의 진행 순서

| 차시 | 이번에 더할 블록 | 완료 화면 |
| --- | --- | --- |
| 2 | 화면 상태 보관 | 다시 실행해도 말풍선 유지 |
| 3 | FastAPI 요청 본문 | 서버로 전달된 지난 대화 확인 |
| 4 | 인증된 사용자와 대화 ID | 계정·대화마다 다른 기록 |
| 5 | 최근 두 턴 선택 | 전체 이력과 모델 입력 길이가 다름 |
| 6 | Supabase 이력 복원 | 재로그인 후 기존 말풍선 복원 |
| 7 | 실패 질문 보관과 재시도 | 실패 시 잠금, 성공 시 입력 재개 |
| 8 | 대화별 학습 목표 | 목표와 앞선 답변을 참고하는 연속 대화 |

## 시작 전 확인

- 1차시에서 사용한 llama.cpp 모델 서버를 켜 둡니다.
- Windows CMD에서 수업 가상환경을 사용합니다. 새 환경이면 `python -m venv .venv`, `.venv\Scripts\activate`를 한 번 실행합니다.
- 2차시는 화면이 모델을 직접 부릅니다. 3차시부터 [백엔드 안내](BACKEND_GUIDE.md)의 해당 서버를 먼저 실행합니다.
- 4차시부터 정상 로그인 가능한 Supabase 계정 A·B와 Redis가 필요합니다. 실제 비밀번호는 로그인 폼에서만 입력합니다.
- 6차시부터 Supabase DB 접속 URI를 준비하고 테이블 준비 명령을 실행합니다. 기존 실습 테이블은 지우지 않습니다.
- .env.example을 .env로 복사한 뒤 필요한 값을 채웁니다. 기존 .env는 덮어쓰지 않습니다.

## 완료 확인

1. “나는 반복문을 공부해. 하루에 30분 연습할 수 있어.”라고 전송합니다.
2. “내 상황에 맞춰 내일 할 연습 하나를 알려줘.”라고 이어 묻습니다.
3. 펼친 모델 입력에서 앞선 질문과 답변을 찾습니다.
4. 후반 차시에서는 다시 로그인해 같은 대화를 고르고 이어갑니다.
5. 실패 실습 버튼으로 한 번 실패시킨 뒤 같은 질문 다시 보내기로 복구합니다. 정확한 조작은 해당 차시 교안을 따릅니다.

모델은 답변을 다르게 만들 수 있습니다. 모델 입력에 무엇이 전달되었는지와 그 내용을 답변이 어떻게 사용했는지를 확인합니다.

# 1차시. 앞에서 한 말을 기억하는 대화 만들기

## 1. 학습목표

[수업 전 안내](../TODAY_GUIDE.md)를 먼저 읽습니다.

- 앞선 질문과 답변을 다음 API 요청에 함께 보냅니다.
- 함수 한 곳을 바꿔 이전 내용을 이어서 묻는 대화를 만듭니다.
- 기록을 저장하는 것과 AI에게 전달하는 것의 차이를 설명합니다.

대화형 AI 앱을 만들 때 필요한 **문맥 전달**을 익힙니다.

### 전체 8차시 흐름

| 차시 | 주제 | 직접 확인할 결과 |
| --- | --- | --- |
| 1 | 이전 대화를 메시지 목록에 넣기 | 앞에서 말한 이름과 과일로 답하기 |
| 2 | Streamlit에서 대화 이어가기 | 화면 재실행 후에도 이전 내용으로 답하기 |
| 3 | FastAPI에서 AI 요청 만들기 | 화면에서 보낸 질문을 서버가 처리하기 |
| 4 | 사용자별 세션 컨텍스트 나누기 | 서로 다른 사용자의 대화가 섞이지 않기 |
| 5 | 최근 대화만 골라 보내기 | 긴 기록에서 최근 질문과 답변만 전달하기 |
| 6 | 저장된 대화를 불러와 이어가기 | 다시 로그인한 뒤 기존 기록으로 답하기 |
| 7 | API 실패 뒤 대화 다시 이어가기 | 실패한 요청이 기록 순서를 깨뜨리지 않기 |
| 8 | 나만의 학습 도우미 완성하기 | 목표와 이전 질문을 참고해 학습 대화 이어가기 |

2차시부터 화면 상태를 재사용하고, 이후 기존 FastAPI·인증·Redis·Supabase를 필요한 순서에 연결합니다.

## 2. 중요 알고리즘 및 코드를 읽을 때 반드시 알아야 할 내용

### 기록해 두었는데 왜 다시 묻는 걸까?

먼저 “내 이름은 민수고 좋아하는 과일은 귤이야”라고 말했습니다. 다음에 “내 이름과 좋아하는 과일이 뭐야?”라고 물었는데 AI가 모른다고 답할 수 있습니다. 프로그램에 남긴 기록을 이번 API 요청에 넣지 않았기 때문입니다.

대화 기록은 메모장과 같습니다. 메모장에 적어 두기만 하면 상대방은 읽을 수 없습니다. 새 질문을 할 때 그 메모도 함께 건네야 합니다.

이 실습에서는 이전 질문과 답변을 담은 `history` 목록을 **세션 컨텍스트**라고 부릅니다. `messages`는 이번에 AI에게 보낼 목록입니다. `history`를 `messages`에 넣는 것이 이번에 배울 “컨텍스트 주입”입니다.

### 메시지 한 개는 누가 한 말인지와 내용으로 구성된다

| 항목 | 뜻 | 예 |
| --- | --- | --- |
| role | 누가 한 말인가 | user는 내 질문, assistant는 AI 답변 |
| content | 어떤 말을 했는가 | 내 이름은 민수야 |
| system 메시지 | 프로그램이 정한 답변 안내 | 한국어로 짧게 답하기 |

질문과 답변을 모두 남겨야 “방금 네가 말한 두 번째 방법”처럼 AI 답변을 가리키는 질문도 이어갈 수 있습니다. 질문 한 번과 답변 한 번이 한 턴이며, 이를 여러 번 이어가는 대화가 멀티턴 대화입니다.

### 이번에 바꿀 함수

main.py의 `build_messages()`를 아래처럼 바꿉니다. 수정하는 것은 마지막 줄에 `history`를 더하는 부분입니다.

```python
def build_messages(history, question):
    current = [{"role": "user", "content": question}]
    return [SYSTEM_MESSAGE] + history + current
```

`+`는 목록들을 순서대로 잇습니다. 답변 안내 뒤에 지난 대화를 붙이고, 마지막에 현재 질문을 넣습니다. 이 목록이 `client.chat.completions.create()`의 messages로 전달됩니다.

답변은 서버 응답의 `response.choices[0].message.content`에서 꺼냅니다. 성공한 질문과 답변은 main.py가 history에 차례로 추가합니다. 다음 질문에서는 그 목록을 다시 사용합니다. 현재 프로그램을 종료하면 이 임시 목록도 사라집니다.

참고: [공식 대화 상태 안내](https://developers.openai.com/api/docs/guides/conversation-state), [위키독스 멀티턴 예제](https://wikidocs.net/217882).

## 3. 코드 제공

### 먼저 실행하기

전체 코드는 같은 폴더의 [main.py](main.py)에 있습니다. 시작 코드는 현재 질문만 보내는 작은 대화 프로그램입니다. 실행해 차이를 본 뒤, 위의 함수로 바꿉니다.

[모델 API 준비](../BACKEND_GUIDE.md)를 마치고 서버 CMD는 켜 둡니다. 별도 Windows CMD에서 아래 명령을 순서대로 실행합니다. 압축을 다른 곳에 풀었다면 첫 경로를 바꿉니다.

```bat
cd /d C:\AI4\MultiTurn_Context\lesson01
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
copy .env.example .env
python main.py
```

가상환경을 만들고 필요한 패키지를 설치한 뒤 프로그램을 실행합니다. 이미 정상 수업 가상환경을 사용 중이면 생성·활성화 두 줄은 생략합니다. 기존 .env가 있으면 복사 대신 현재 값을 확인합니다.

기본 .env에는 다음 세 항목이 들어 있습니다. `local-chat`은 모델 서버를 시작할 때 정한 별명과 같습니다.

```dotenv
LLM_BASE_URL=http://127.0.0.1:8080/v1
LLM_MODEL=local-chat
LLM_API_KEY=local-not-used
```

### 1단계. 앞선 내용이 전달되지 않는 상황 보기

프로그램이 시작되면 같은 CMD에 두 문장을 차례로 입력합니다.

```text
나: 내 이름은 민수고 좋아하는 과일은 귤이야.
나: 내 이름과 좋아하는 과일이 뭐야?
```

실제로 입력할 것은 `나:` 뒤의 문장입니다. 두 번째 질문에도 **함께 보내는 이전 메시지: 0 개**가 표시되는지 봅니다. AI가 앞선 사실을 모르거나 추측할 수 있습니다. history에 기록은 남지만 build_messages가 그 기록을 사용하지 않는 상태입니다.

### 2단계. 함수 한 곳 바꾸기

`종료`를 입력해 프로그램을 끝냅니다. main.py에서 **build_messages 함수만 2번 항목의 함수로 교체**하고 저장합니다. 다른 입력·API 호출·기록 부분은 그대로 둡니다.

같은 CMD에서 `python main.py`로 다시 시작하고, 1단계의 두 문장을 다시 입력합니다.

### 3단계. 같은 질문으로 달라진 결과 확인하기

두 번째 질문에서 다음과 같이 보이는지 확인합니다. 아래 AI 문장은 설명용 예상 예시입니다.

```text
함께 보내는 이전 메시지: 2 개
AI: 이름은 민수이고 좋아하는 과일은 귤입니다.
```

정확한 답변 문장은 달라질 수 있습니다. **이전 메시지가 2개 포함되었고, 앞에서 알려준 이름과 과일을 사용했는지** 확인합니다.

이어서 `그 과일을 좋아하는 나에게 간식 하나만 추천해줘.`라고 입력합니다. 이번에는 이전 메시지 4개가 전달됩니다. 앞선 정보를 참고한 추천인지 읽어 봅니다.

끝내려면 `종료`를 입력합니다. 프로그램을 다시 실행하면 새 대화가 시작되므로, 앞선 정보를 다시 말해 줍니다.

<details>
<summary>실행이 안 되거나 이전 메시지가 계속 0개일 때</summary>

- 이전 메시지가 계속 0개면 build_messages의 마지막 줄에 history가 들어 있는지 확인합니다.
- 연결할 수 없으면 모델 서버 CMD가 켜져 있는지 확인합니다.
- 모델을 찾지 못하면 .env의 LLM_MODEL과 서버의 별명을 맞춥니다.
- .env를 바꾸었으면 프로그램을 종료하고 다시 실행합니다.
- 빈 질문은 API에 보내지 않습니다. 요청 실패나 빈 답변도 대화 기록에 추가하지 않으므로 질문을 다시 입력하면 됩니다.

</details>

답변이 학습 주제와 시간을 함께 참고했는지 확인합니다. 수정한 함수와 두 번째 요청의 이전 메시지 개수, 답변에서 참고한 내용 한 문장을 남깁니다. 먼저 직접 시도하고 막히는 부분만 AI에 질문합니다.

# 2차시. 화면이 다시 실행되어도 대화 이어가기

## 1. 학습목표

[수업 전 안내](../TODAY_GUIDE.md)를 먼저 확인합니다.

- 화면 다시 실행 후에도 앞선 말풍선을 남깁니다.
- 다음 질문에 앞선 질문과 답변을 함께 보냅니다.

## 2. 중요 알고리즘 및 코드를 읽을 때 반드시 알아야 할 내용

“내 이름은 민수야”라고 말한 뒤 화면 다시 실행을 누르자 말풍선이 없어집니다. 화면이 다시 그려질 때 기록까지 새 목록으로 바뀌기 때문입니다.

`session_state`는 같은 브라우저 연결에서 다시 실행할 때 꺼내 쓰는 보관함입니다. **보관함이 없을 때만 만들고, 이미 있으면 그대로 사용**합니다. 브라우저 새로고침이나 연결 종료까지 보장하는 영구 저장소는 아닙니다.

`[규칙] + [이전 질문·답변] + [현재 질문]` 순서로 AI에게 보냅니다. 여기서 `+`는 숫자 계산이 아니라 목록 연결입니다. 질문 한 개와 답변 한 개가 한 턴입니다.

`st.chat_input()`은 타이핑 중인 초안을 계속 돌려주지 않습니다. 전송한 시점에 질문 문자열을 반환합니다. 성공한 질문과 답변만 messages에 추가합니다.

### 수정 전 위치와 이번에 바꿀 함수

`ensure_history()`가 `st.session_state["messages"] = []`를 매번 실행합니다. 버튼을 눌러도 파일 전체가 다시 실행되므로 기록이 덮어써집니다.

수정할 파일은 **lesson02/main.py**입니다. 아래 함수로 교체합니다. 전체 실행 코드는 [main.py](main.py)에 있으며, 여기는 수정할 부분만 표시합니다.

```python
def ensure_history():
    if "messages" not in st.session_state:
        st.session_state["messages"] = []
```

참고: [Streamlit 공식 대화 예제](https://docs.streamlit.io/develop/tutorials/chat-and-llm-apps/build-conversational-apps), [위키독스 챗봇 예제](https://wikidocs.net/352332).

## 3. 코드 제공

### 준비와 실행

Windows CMD에서 현재 차시 폴더로 이동합니다. 기존 수업 가상환경을 사용하거나 처음 한 번만 생성·활성화합니다. [서버 실행 안내](../BACKEND_GUIDE.md)에서 이번 차시에 해당하는 서버를 먼저 준비합니다.

```bat
cd /d C:\AI4\MultiTurn_02_08\lesson02
python -m pip install -r requirements.txt
copy .env.example .env
python -m streamlit run main.py --server.address 127.0.0.1 --server.port 8501
```

패키지를 설치하고 설정 예시를 복사한 뒤 화면 서버를 실행합니다. **기존 .env가 있으면 복사로 덮어쓰지 말고 값을 확인**합니다. 파일 미리보기가 아니라 브라우저의 http://127.0.0.1:8501 에서 실습합니다. 종료는 이 CMD에서 Ctrl+C입니다.

화면 폴더의 .env에는 1차시와 같은 LLM_BASE_URL·LLM_MODEL·LLM_API_KEY가 필요합니다.

### 실행해 보고 한 곳 바꾸기

1. `내 이름은 민수고 좋아하는 과일은 귤이야.`를 전송합니다. 답변이 표시된 뒤 **화면 다시 실행**을 누릅니다. 시작 코드에서는 말풍선이 사라집니다.
2. `ensure_history()`만 위 코드로 교체하고 파일을 저장합니다. 화면이 다시 실행됩니다.
3. **새 대화**를 누르고 이름·과일 문장을 다시 전송합니다. **화면 다시 실행**을 눌러도 두 말풍선이 남아야 합니다.
4. `내 이름과 좋아하는 과일은 뭐야?`를 전송합니다. 이전 메시지 개수가 2로 표시되고, 답변이 앞선 정보를 참고하는지 확인합니다. 같은 브라우저 탭에서 진행합니다.

정확한 AI 문장은 달라질 수 있습니다. 먼저 펼친 모델 입력과 말풍선 개수를 확인한 뒤 답변이 앞선 내용을 참고했는지 읽습니다.

<details>
<summary>실행이 멈추거나 화면이 비어 있을 때</summary>

- 다운로드한 파일의 미리보기 대신 CMD에 표시된 Streamlit 주소를 엽니다.
- 제목도 보이지 않으면 브라우저에서 Ctrl+Shift+R을 누르고 실행 CMD의 오류를 확인합니다. [공통 문제 해결](../TROUBLESHOOTING.md)을 참고합니다.
- 제목과 연결 오류가 보이면 이번 차시의 backend와 모델 서버 CMD를 확인합니다. 로그인 차시는 Redis도 실행 중이어야 합니다.
- 설정 파일은 실행한 폴더의 .env를 읽습니다. 다른 차시 .env를 편집한 것은 아닌지 확인합니다.
- 연결·모델 오류는 성공 기록에 넣지 않습니다. 로그인 만료 안내가 나오면 다시 로그인합니다.

</details>

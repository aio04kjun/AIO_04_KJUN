## 2. 중요 알고리즘 및 코드를 읽을 때 반드시 알아야 할 내용

질문이 쌓일수록 같은 긴 기록을 매번 보냅니다. 이번에는 메모장 전체를 화면에 남겨 두고, AI에게 건네는 쪽지만 최근 두 턴으로 줄입니다.

한 턴은 `[질문, 답변]` 두 메시지입니다. 최근 두 턴이면 네 메시지이므로 `history[-4:]`를 사용합니다. `-4`는 뒤에서 네 번째 위치, `:`는 그 위치부터 끝까지라는 뜻입니다.

`[system] + [최근 질문·답변 4개] + [현재 질문]`으로 구성합니다. 전체 기록이 여섯 메시지여도 다음 모델 입력은 최대 여섯 메시지입니다. system 하나와 현재 질문 하나가 더해지기 때문입니다.

오래된 정보는 이 범위를 벗어나면 전달되지 않습니다. 이 방법은 메시지 개수를 줄일 뿐, 토큰 개수를 정확히 계산하거나 모든 긴 질문을 처리하는 방법은 아닙니다. 입력 내용에 따라 AI의 문맥 한도를 넘을 수 있습니다.

### 수정 전 위치와 이번에 바꿀 함수

backend05/main.py의 `build_messages()`는 `return [SYSTEM_MESSAGE] + history + current`로 되어 있습니다. 화면 이력을 전부 전달합니다.

수정할 파일은 **backend05/main.py**입니다. 아래 함수로 교체합니다. 전체 실행 코드는 [main.py](main.py)에 있으며, 여기는 수정할 부분만 표시합니다.

```python
def build_messages(history, question):
    current = [{"role": "user", "content": question}]
    return [SYSTEM_MESSAGE] + history[-4:] + current
```

참고: [공식 대화 상태 안내](https://developers.openai.com/api/docs/guides/conversation-state), [위키독스 챗봇 예제](https://wikidocs.net/352332).

## 3. 코드 제공

### 준비와 실행

Windows CMD에서 현재 차시 폴더로 이동합니다. 기존 수업 가상환경을 사용하거나 처음 한 번만 생성·활성화합니다. [서버 실행 안내](../BACKEND_GUIDE.md)에서 이번 차시에 해당하는 서버를 먼저 준비합니다.

```bat
cd /d C:\AI4\MultiTurn_02_08\lesson05
python -m pip install -r requirements.txt
copy .env.example .env
python -m streamlit run main.py --server.address 127.0.0.1 --server.port 8501
```

패키지를 설치하고 설정 예시를 복사한 뒤 화면 서버를 실행합니다. **기존 .env가 있으면 복사로 덮어쓰지 말고 값을 확인**합니다. 파일 미리보기가 아니라 브라우저의 http://127.0.0.1:8501 에서 실습합니다. 종료는 이 CMD에서 Ctrl+C입니다.

화면 폴더의 .env에는 `API_BASE_URL=http://127.0.0.1:8000`을 사용합니다. 모델 키와 DB 접속 값은 백엔드 폴더의 .env에만 둡니다. 이번 차시는 **backend05**와 연결합니다.

### 실행해 보고 한 곳 바꾸기

1. **새 대화**를 누른 뒤 `나는 귤을 좋아해.`, `오늘은 반복문을 공부해.`, `지금은 for문 예제를 보고 있어.`를 순서대로 전송합니다.
2. 네 번째로 `앞에서 말한 내용을 참고해 다음 연습 하나를 알려줘.`를 전송합니다. 시작 코드의 직전 모델 입력에는 이전 메시지가 6개, 전체가 8개입니다.
3. **backend05/main.py**의 `build_messages()`를 위 코드로 교체합니다. 백엔드 CMD에서 Ctrl+C를 누르고 같은 실행 명령으로 다시 시작합니다. 모델 서버는 켜 둡니다.
4. 같은 화면·같은 대화에서 `이번에는 연습 조건 하나만 더 붙여줘.`를 전송합니다. 저장된 말풍선은 남고 모델 입력에는 **이전 4개 + system 1개 + 현재 질문 1개**만 있어야 합니다.
5. 펼친 모델 입력의 첫 이전 메시지가 user인지, 이어 assistant가 나오는지 확인합니다. 질문·답변 한 쌍을 중간에서 끊지 않았는지 보는 것입니다.

정확한 AI 문장은 달라질 수 있습니다. 먼저 펼친 모델 입력과 말풍선 개수를 확인한 뒤 답변이 앞선 내용을 참고했는지 읽습니다.

<details>
<summary>실행이 멈추거나 화면이 비어 있을 때</summary>

- 다운로드한 파일의 미리보기 대신 CMD에 표시된 Streamlit 주소를 엽니다.
- 제목도 보이지 않으면 브라우저에서 Ctrl+Shift+R을 누르고 실행 CMD의 오류를 확인합니다. [공통 문제 해결](../TROUBLESHOOTING.md)을 참고합니다.
- 제목과 연결 오류가 보이면 이번 차시의 backend와 모델 서버 CMD를 확인합니다. 로그인 차시는 Redis도 실행 중이어야 합니다.
- 설정 파일은 실행한 폴더의 .env를 읽습니다. 다른 차시 .env를 편집한 것은 아닌지 확인합니다.
- 연결·모델 오류는 성공 기록에 넣지 않습니다. 로그인 만료 안내가 나오면 다시 로그인합니다.

# 8차시. 학습 목표를 반영하는 대화 도우미 완성하기

## 1. 학습목표

[수업 전 안내](../TODAY_GUIDE.md)를 먼저 확인합니다.

- 대화별 학습 목표를 저장합니다.
- 목표와 최근 대화를 함께 넣어 후속 질문을 이어갑니다.

## 2. 중요 알고리즘 및 코드를 읽을 때 반드시 알아야 할 내용

반복문을 공부하려고 만든 대화인데 답변이 일반적인 설명으로 흘러갑니다. 대화 목표를 저장하는 것만으로는 부족하고, 실제 모델 입력에도 넣어야 합니다.

이번에는 대화를 만들 때 제목과 목표를 함께 저장합니다. FastAPI가 선택된 대화의 목표를 DB에서 읽어 `build_system_message(goal)`에 전달합니다. 목표는 대화에 속하므로 다른 대화를 선택하면 그 대화의 목표가 적용됩니다. 기존 대화의 목표를 수정하는 화면은 없으며, 다른 목표를 쓰려면 새 대화를 만듭니다.

`[답변 안내 + 이번 목표] + [최근 두 턴] + [현재 질문]`이 실제 모델 입력입니다. 코드에서 문자열의 `+`는 문장을 이어 붙이고, 메시지 목록의 `+`는 항목을 순서대로 연결합니다.

최근 질문을 참고해야 “그 방법으로 예제를 만들어줘”를 이해하고, 목표를 참고해야 예제를 학습 목적에 맞출 수 있습니다. 답변 문장이 매번 같을 필요는 없습니다. 목표가 모델 입력에 들어갔는지와 실제 답변이 목표와 앞선 질문을 참고하는지를 나누어 확인합니다.

이처럼 만든 messages는 이후 도구 호출이나 상태 흐름을 배우는 수업에서도 모델에 넘기는 입력으로 재사용할 수 있습니다.

### 수정 전 위치와 이번에 바꿀 함수

backend08/main.py의 `build_system_message(goal)`은 `return dict(SYSTEM_MESSAGE)`만 실행합니다. 목표를 DB에서 읽어도 AI 안내에는 넣지 않습니다.

수정할 파일은 **backend08/main.py**입니다. 아래 함수로 교체합니다. 전체 실행 코드는 [main.py](main.py)에 있으며, 여기는 수정할 부분만 표시합니다.

```python
def build_system_message(goal):
    return {
        "role": "system",
        "content": SYSTEM_MESSAGE["content"] + " 이번 대화의 학습 목표: " + goal,
    }
```

참고: [공식 대화 상태 안내](https://developers.openai.com/api/docs/guides/conversation-state), [위키독스 챗봇 예제](https://wikidocs.net/352332).

## 3. 코드 제공

### 준비와 실행

Windows CMD에서 현재 차시 폴더로 이동합니다. 기존 수업 가상환경을 사용하거나 처음 한 번만 생성·활성화합니다. [서버 실행 안내](../BACKEND_GUIDE.md)에서 이번 차시에 해당하는 서버를 먼저 준비합니다.

```bat
cd /d C:\AI4\MultiTurn_02_08\lesson08
python -m pip install -r requirements.txt
copy .env.example .env
python -m streamlit run main.py --server.address 127.0.0.1 --server.port 8501
```

패키지를 설치하고 설정 예시를 복사한 뒤 화면 서버를 실행합니다. **기존 .env가 있으면 복사로 덮어쓰지 말고 값을 확인**합니다. 파일 미리보기가 아니라 브라우저의 http://127.0.0.1:8501 에서 실습합니다. 종료는 이 CMD에서 Ctrl+C입니다.

화면 폴더의 .env에는 `API_BASE_URL=http://127.0.0.1:8000`을 사용합니다. 모델 키와 DB 접속 값은 백엔드 폴더의 .env에만 둡니다. 이번 차시는 **backend08**와 연결합니다.

### 실행해 보고 한 곳 바꾸기

1. 대화 제목을 `구구단 연습`, 목표를 `파이썬 반복문으로 구구단 만들기`로 입력해 대화를 만듭니다.
2. `처음 연습할 것 하나를 알려줘.`를 전송합니다. 직전 모델 입력의 system을 펼칩니다. 시작 코드에서는 목표 문장이 빠져 있습니다. 답변이 우연히 주제에 맞아도 모델 입력을 기준으로 확인합니다.
3. **backend08/main.py**의 `build_system_message()`만 위 코드로 교체합니다. 백엔드 CMD에서 Ctrl+C 후 같은 명령으로 다시 시작합니다.
4. 같은 대화에서 `그 방법으로 아주 짧은 예제 하나를 만들어줘.`를 전송합니다. system에 목표가 들어가고, 앞선 질문·답변도 포함되어야 합니다.
5. 별도 대화를 만들고 목표를 `파이썬 리스트에서 최댓값 찾기`로 지정합니다. 같은 첫 질문을 보내고 해당 목표가 모델 입력에 들어가는지 비교합니다.
6. 다시 로그인해 `구구단 연습` 대화를 선택합니다. 목표와 말풍선이 복원되는지 확인한 뒤 `앞선 예제에서 내가 바꿔볼 숫자 하나를 알려줘.`로 이어갑니다. 마지막으로 7차시의 실패 버튼으로 한 번 실패시킨 뒤 같은 질문 다시 보내기로 복구합니다.

정확한 AI 문장은 달라질 수 있습니다. 먼저 펼친 모델 입력과 말풍선 개수를 확인한 뒤 답변이 앞선 내용을 참고했는지 읽습니다.

<details>
<summary>실행이 멈추거나 화면이 비어 있을 때</summary>

- 다운로드한 파일의 미리보기 대신 CMD에 표시된 Streamlit 주소를 엽니다.
- 제목도 보이지 않으면 브라우저에서 Ctrl+Shift+R을 누르고 실행 CMD의 오류를 확인합니다. [공통 문제 해결](../TROUBLESHOOTING.md)을 참고합니다.
- 제목과 연결 오류가 보이면 이번 차시의 backend와 모델 서버 CMD를 확인합니다. 로그인 차시는 Redis도 실행 중이어야 합니다.
- 설정 파일은 실행한 폴더의 .env를 읽습니다. 다른 차시 .env를 편집한 것은 아닌지 확인합니다.
- 연결·모델 오류는 성공 기록에 넣지 않습니다. 로그인 만료 안내가 나오면 다시 로그인합니다.

</details>

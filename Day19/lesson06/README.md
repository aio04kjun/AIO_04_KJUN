# 6차시. Supabase 기록을 불러와 대화 이어가기

## 1. 학습목표

[수업 전 안내](../TODAY_GUIDE.md)를 먼저 확인합니다.

- 로그아웃한 뒤에도 저장된 질문·답변을 다시 표시합니다.
- 서버가 DB 이력을 읽어 후속 질문에 사용하도록 연결합니다.

## 2. 중요 알고리즘 및 코드를 읽을 때 반드시 알아야 할 내용

다시 로그인하니 말풍선이 없어졌습니다. 화면 보관함이나 임시 대화 ID 대신, 로그인한 계정의 DB 대화 목록을 읽어야 합니다.

이제 질문과 답변 한 쌍을 Supabase PostgreSQL의 turns 한 행에 저장합니다. 서버가 답변을 얻지 못하면 그 행을 만들지 않습니다. 같은 저장 작업을 식별하는 request_id도 함께 보관합니다.

| 저장 위치 | 역할 | 로그아웃 후 |
| --- | --- | --- |
| session_state | 화면 선택과 로그인 정보 | 정리됨 |
| Redis | 로그인 허용 정보와 만료 시간 | 앱 로그아웃 시 해당 등록 삭제 |
| Supabase DB | 소유자별 대화와 성공한 질문·답변 | 남아 있음 |

DB의 각 행은 question과 answer를 가지므로 `read_history()`가 이를 user와 assistant 메시지로 펼칩니다. `extend([질문, 답변])`는 기존 목록 뒤에 두 항목을 붙입니다. 서버는 이 목록의 최근 네 메시지를 다음 질문 앞에 넣습니다.

화면의 load_history는 API가 반환한 목록 전체를 표시해야 합니다. `data[-2:]`는 마지막 두 개만 선택하며, `data`는 받은 목록 전체입니다. 기존 kdt_user_chat 기록은 바꾸지 않고 별도의 kdt_multiturn 스키마에서 시작합니다.

### 수정 전 위치와 이번에 바꿀 함수

`load_history()`의 마지막 줄은 `return data[-2:]`입니다. 서버에서 받은 목록 중 마지막 질문과 답변만 화면에 돌려줍니다.

수정할 파일은 **lesson06/main.py**입니다. 아래 함수로 교체합니다. 전체 실행 코드는 [main.py](main.py)에 있으며, 여기는 수정할 부분만 표시합니다.

```python
def load_history(conversation_id):
    data = api("GET", f"/conversations/{conversation_id}/messages")
    return data
```

참고: [Psycopg 트랜잭션](https://www.psycopg.org/psycopg3/docs/basic/transactions.html), [공식 대화 상태 안내](https://developers.openai.com/api/docs/guides/conversation-state).

## 3. 코드 제공

### 준비와 실행

Windows CMD에서 현재 차시 폴더로 이동합니다. 기존 수업 가상환경을 사용하거나 처음 한 번만 생성·활성화합니다. [서버 실행 안내](../BACKEND_GUIDE.md)에서 이번 차시에 해당하는 서버를 먼저 준비합니다.

```bat
cd /d C:\AI4\MultiTurn_02_08\lesson06
python -m pip install -r requirements.txt
copy .env.example .env
python -m streamlit run main.py --server.address 127.0.0.1 --server.port 8501
```

패키지를 설치하고 설정 예시를 복사한 뒤 화면 서버를 실행합니다. **기존 .env가 있으면 복사로 덮어쓰지 말고 값을 확인**합니다. 파일 미리보기가 아니라 브라우저의 http://127.0.0.1:8501 에서 실습합니다. 종료는 이 CMD에서 Ctrl+C입니다.

화면 폴더의 .env에는 `API_BASE_URL=http://127.0.0.1:8000`을 사용합니다. 모델 키와 DB 접속 값은 백엔드 폴더의 .env에만 둡니다. 이번 차시는 **backend06**와 연결합니다.

### 실행해 보고 한 곳 바꾸기

1. 로그인하고 **새 대화 제목**에 `복원 실습`을 넣어 **대화 만들기**를 누릅니다. 선택된 ID 앞부분을 메모합니다.
2. `내 이름은 민수야.`와 `나는 파이썬 반복문을 공부해.`를 차례로 전송합니다. 시작 코드에서는 마지막 질문·답변 두 말풍선만 보입니다.
3. lesson06/main.py의 `load_history()`를 위 코드로 교체합니다. 같은 대화에서 두 질문과 두 답변, 총 네 말풍선이 보이는지 확인합니다.
4. **계정 바꾸기 / 로그아웃** 후 같은 계정으로 다시 로그인합니다. 목록에서 앞서 메모한 대화를 고르면 네 말풍선이 복원되어야 합니다. 새 대화를 만들지 않습니다.
5. `내 이름과 공부하는 주제가 뭐야?`를 전송합니다. 직전 모델 입력에는 DB에서 불러온 이전 메시지 네 개가 들어 있어야 합니다. B 계정으로 바꾸면 A의 대화 제목이 목록에 나타나지 않아야 합니다.

정확한 AI 문장은 달라질 수 있습니다. 먼저 펼친 모델 입력과 말풍선 개수를 확인한 뒤 답변이 앞선 내용을 참고했는지 읽습니다.
